## 二、建议替换文本

### 5.1 测试内容1：指标1 可再生能源电/热/燃料联产系统多能转化模型

#### 5.1.1 测试原理

可再生能源电/热/燃料联产系统多能转化模型是综合能源系统设计与运行仿真的基础模型库。中期阶段考核重点为：多能转化单元模块库是否覆盖不少于5种多能转化类型，是否形成与多能转化类型相匹配的单元模块，并且每个单元模块是否具有明确的输入、输出、关键参数和计算关系。

本测试以当前已有的多能转化单元模块库代码和模型设计说明书为测试对象。测试人员通过审查源代码、说明书和测试样例数据，逐项核验各单元模块的输入变量、输出变量、关键参数和能量转换关系；对于可以通过公式或时序曲线计算输出的模块，采用典型样例数据进行单元级计算检查。

本测试不要求自动生成系统拓扑，不评价优化算法的全局最优性，也不要求所有预留模块均完成系统级场景接入。对当前代码中已有但尚未在松山湖系统级流程中完整使用的模块，仅进行单元模块级输入输出和公式计算测试；松山湖冷热电案例用于检查已使用设备与单元模块库之间的对应关系，并验证模块库在已有案例中的基本调用能力。

本测试输入包括多能转化单元模块库源代码、模型设计说明书、单元模块测试数据、单元模块测试记录模板、松山湖和德国已有案例中的设备清单及相应源荷数据。测试输出包括多能转化类型统计结果、单元模块输入输出检查结果、样例计算结果、已有案例模块匹配结果和测试结论记录。

#### 5.1.2 计算方式

本测试采用“输入数据—单元模块—输出数据”的方式核验多能转化模型。对于每类单元模块，测试人员给定一组测试输入数据，按照模型公式计算输出，并检查输出字段、数值范围和转换关系是否正确。

为便于第三方测试人员核对公式与输入输出关系，以下各单元模块测试表中的变量名称与公式变量保持一致，并在括号中说明变量含义和单位。实际测试数据文件中的字段名称可由被测单位按代码接口提供，但测试记录中应能对应到下列表格中的公式变量。

1、动力发电单元

动力发电单元以天然气为输入，同时输出电力和热力。热电联产机组的基本计算式为：

```text
P_ele = η_ele × Q_gas
Q_heat = η_heat × Q_gas
```

其中，`Q_gas`为天然气输入功率，`P_ele`为电力输出功率，`Q_heat`为热力输出功率，`η_ele`为发电效率，`η_heat`为供热效率。

| 项目 | 内容 |
|---|---|
| 单元模块名称 | 动力发电单元 |
| 涵盖设备 | 热电联产机组CHP |
| 输入数据 | `Q_gas`（天然气输入功率，kW）、`η_ele`（发电效率）、`η_heat`（供热效率） |
| 输出数据 | `P_ele`（电力输出功率，kW）、`Q_heat`（热力输出功率，kW） |
| 测试步骤 | 加载动力发电单元参数，输入样例天然气功率和效率参数，按公式计算电力和热力输出，记录计算结果。 |
| 测试重点 | 检查气制电、气制热两类转换关系是否成立 |

2、余热利用单元

余热利用单元当前以吸收式制冷机为测试对象，利用热力和少量辅助电力制取冷量。基本计算式为：

```text
Q_cool = COP × (Q_heat + W_ele)
```

其中，`Q_cool`为冷量输出，`Q_heat`为驱动热源输入，`W_ele`为辅助电输入，`COP`为制冷系数。

| 项目 | 内容 |
|---|---|
| 单元模块名称 | 余热利用单元 |
| 涵盖设备 | 吸收式制冷机 |
| 输入数据 | `Q_heat`（驱动热源输入，kW）、`W_ele`（辅助电输入，kW）、`COP`（制冷系数） |
| 输出数据 | `Q_cool`（冷量输出，kW） |
| 测试步骤 | 加载余热利用单元参数，输入测试热源、辅助电和COP参数，按公式计算冷量输出，记录计算结果。 |
| 测试重点 | 检查热制冷转换关系是否成立 |

3、风力发电单元

风力发电单元根据风速和风机功率曲线计算电力输出。基本计算式为：

```text
P = 0,                                      v < v_ci
P = P_r × (v^3 - v_ci^3)/(v_r^3 - v_ci^3), v_ci ≤ v < v_r
P = P_r,                                   v_r ≤ v < v_co
P = 0,                                      v ≥ v_co
```

其中，`v`为风速，`P`为风电输出功率，`P_r`为额定功率，`v_ci`为切入风速，`v_r`为额定风速，`v_co`为切出风速。

| 项目 | 内容 |
|---|---|
| 单元模块名称 | 风力发电单元 |
| 涵盖设备 | 风力发电机 |
| 输入数据 | `v`（风速，m/s）、`P_r`（额定功率，kW）、`v_ci`（切入风速，m/s）、`v_r`（额定风速，m/s）、`v_co`（切出风速，m/s） |
| 输出数据 | `P`（风电输出功率，kW） |
| 测试步骤 | 加载风力发电单元参数，输入样例风速序列，计算风电出力曲线，检查边界风速对应输出是否合理。 |
| 测试重点 | 检查风转电转换关系和边界风速处理是否正确 |

4、光伏发电单元

光伏发电单元根据太阳辐射、环境温度和光伏额定容量计算电力输出。基本计算式为：

```text
P = P_r × η × (G/1000) × [1 + α × (T - T_ref)]
```

其中，`P`为光伏输出功率，`P_r`为额定功率，`η`为系统效率，`G`为太阳辐射强度，`α`为温度系数，`T`为环境温度，`T_ref`为参考温度。

| 项目 | 内容 |
|---|---|
| 单元模块名称 | 光伏发电单元 |
| 涵盖设备 | 光伏发电机 |
| 输入数据 | `G`（太阳辐射强度，W/m²）、`T`（环境温度，°C）、`P_r`（额定功率，kW）、`η`（系统效率）、`α`（温度系数，1/°C）、`T_ref`（参考温度，°C） |
| 输出数据 | `P`（光伏输出功率，kW） |
| 测试步骤 | 加载光伏发电单元参数，输入样例太阳辐射和环境温度，按公式计算光伏输出功率，并检查输出非负。 |
| 测试重点 | 检查光转电转换关系，太阳辐射为0时输出应为0 |

5、电热转化单元

电热转化单元包括电热泵和电制冷机。电热泵将电力转化为热力，电制冷机将电力转化为冷量。基本计算式为：

```text
Q_heat = COP_h × W_ele
Q_cool = COP_c × W_ele
```

其中，`W_ele`为电力输入，`Q_heat`为热力输出，`Q_cool`为冷量输出，`COP_h`和`COP_c`分别为制热系数和制冷系数。

| 项目 | 内容 |
|---|---|
| 单元模块名称 | 电热转化单元 |
| 涵盖设备 | 电热泵、电制冷机 |
| 输入数据 | `W_ele`（电力输入，kW）、`COP_h`（制热系数）、`COP_c`（制冷系数） |
| 输出数据 | `Q_heat`（热力输出，kW）、`Q_cool`（冷量输出，kW） |
| 测试步骤 | 加载电热转化单元参数，输入样例电力功率和COP参数，按公式计算热力或冷量输出。 |
| 测试重点 | 检查电制热、电制冷转换关系是否成立 |

6、储能单元

储能单元用于描述电储能、热储能和冷储能设备的充放状态变化。中期测试只检查储能状态方程和容量边界，储能单元作为动态平衡支撑模块，不作为新增多能转化类型数量达标的唯一依据。基本计算式为：

```text
E(t+1) = E(t) × (1 - σ) + P_ch × η_ch - P_dis / η_dis
```

其中，`E(t)`为当前储能量，`P_ch`为充能功率，`P_dis`为放能功率，`η_ch`为充能效率，`η_dis`为放能效率，`σ`为自损耗率。

| 项目 | 内容 |
|---|---|
| 单元模块名称 | 储能单元 |
| 涵盖设备 | 电储能、热储能、冷储能 |
| 输入数据 | `E(t)`（当前储能量，kWh）、`P_ch`（充能功率，kW）、`P_dis`（放能功率，kW）、`η_ch`（充能效率）、`η_dis`（放能效率）、`σ`（自损耗率）、`E_max`（储能容量上限，kWh） |
| 输出数据 | `E(t+1)`（下一时段储能量，kWh） |
| 测试步骤 | 加载储能单元参数，输入测试初始储能量和充放功率，按状态方程计算下一时段储能量，并检查容量边界。 |
| 测试重点 | 检查储能状态更新和容量边界是否合理 |

#### 5.1.3 测试步骤

可再生能源电/热/燃料联产系统多能转化模型测试按下列步骤进行：

第1步：被测单位提交多能转化单元模块库源代码、模型设计说明书、单元模块测试样例数据和测试记录模板。测试人员确认测试环境中能够打开单元模块库代码，并记录代码版本和文件目录。

第2步：测试人员审查单元模块库目录，记录每类单元模块对应的单元模块名称、涵盖设备、输入能量形式、输出能量形式和能源转换形式，统计多能转化类型数量。

第3步：测试人员按照表5.1-1核对多能转化类型统计口径，确认可统计的多能转化类型不少于5种，且每种类型均有相匹配的单元模块。

第4步：测试人员按照5.1.2中的计算方式，对动力发电、余热利用、风力发电、光伏发电、电热转化等核心单元模块执行样例计算，检查输出结果是否与公式一致，并填写单元模块测试记录。

第5步：对于储能单元，测试人员执行单元级输入输出检查和状态方程计算，记录其作为动态平衡支撑模块的测试结果。

第6步：在已有冷热电综合能源系统案例中，检查已使用的光伏、风电、CHP、电热泵、电制冷机、吸收式制冷机、储能等设备是否能够与单元模块库中的设备定义对应；其中松山湖案例用于检查冷热电设备匹配关系，风电单元可结合德国已有案例中的风资源数据进行单元级核验。该步骤用于验证模块库在已有案例中的调用或匹配关系，不作为新增场景测试要求。

第7步：测试人员汇总多能转化类型统计结果、单元模块测试结果和已有案例匹配结果，形成测试记录，并对照预期结果和判定准则给出测试结论。

#### 5.1.4 预期结果

根据上述步骤，预期结果如下：

1、多能转化单元模块库中可统计的多能转化类型不少于5种。

2、每种纳入统计的多能转化类型均有相匹配的单元模块，且能够说明输入数据、输出数据和关键参数。

3、动力发电单元能够实现气制电和气制热；余热利用单元能够实现热制冷；风力发电单元能够实现风转电；光伏发电单元能够实现光转电；电热转化单元能够实现电制热和电制冷。

4、核心单元模块能够依据样例输入数据完成公式计算或结果检查，输出结果与计算方式一致。

5、储能单元能够完成单元级输入输出和状态方程检查，作为系统动态平衡支撑模块的测试材料。

6、已有案例中已使用的主要设备能够与单元模块库中的设备定义形成对应关系，并可形成模块匹配记录；如测试环境具备运行条件，可同时形成模块调用日志或案例输出结果。

7、测试过程能够形成可复核的记录，包括单元模块清单、多能转化类型统计结果、输入输出说明、样例计算结果、已有案例匹配结果和测试结论。

#### 5.1.5 判定准则

满足以下条件时，本测试项判定为通过：

1、多能转化类型数量不少于5种。

2、每种纳入统计的多能转化类型至少有一个相匹配的单元模块。

3、核心单元模块的输入数据、输出数据和能量转换公式清晰，能够按样例数据完成计算或结果检查。

4、已有案例中已使用的主要设备能够与单元模块库中的设备定义对应。

5、测试记录完整，能够支撑第三方复核。

出现以下任一情况时，本测试项判定为不通过：

1、多能转化类型数量少于5种。

2、统计的多能转化类型没有对应的单元模块。

3、核心单元模块缺少必要输入输出说明，导致测试人员无法执行单元级测试。

4、样例输入数据无法得到对应输出结果，且不能说明原因。

5、已有案例中已使用的主要设备无法与单元模块库中的设备定义形成对应关系。

6、测试记录缺失，无法证明多能转化模型和单元模块库已完成审查或测试。

对于氢能、地源热泵、光热集热器、余热锅炉等当前第一版主流程未接入的设备，不纳入本测试内容的通过判定。对于默认参数补齐、异常配置识别、场景迁移适配等接口能力，可作为后续软件工具包测试或整改建议记录，不作为本测试内容的通过必要条件。
