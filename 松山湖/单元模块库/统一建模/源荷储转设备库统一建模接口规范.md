# 源荷储转设备库统一建模接口规范

## 1. 文档目的

本文档用于定义源、荷、储、转四类设备库的统一建模接口，为后续 EMS 调度、容量优化配置、多场景复用和项目书考核指标计算提供统一依据。

本文档主要回答四个问题：

1. 设备库应该按什么原则建模。
2. 源、荷、储、转四类设备应该暴露哪些统一输入输出接口。
3. EMS 和容量优化应该如何调用设备库。
4. 经济、安全、能效、碳排四类考核指标如何由设备库接口支撑。

## 2. 设备库建模原则

### 2.1 按设备类型建模，不按场景重复建模

设备库应按设备类型抽象，不应为每个场景单独开发一套设备模型。

```text
推荐方式：
源侧设备类 / 负荷设备类 / 储能设备类 / 转换设备类
  -> 具体设备模型
  -> 场景配置选择设备组合和参数

不推荐方式：
松山湖设备模型 / 榆林设备模型 / 大庆设备模型
  -> 每个场景重复开发类似设备
```

这样可以保证不同场景中相同或相近设备复用同一套接口和模型。

### 2.2 相似设备抽象为同一类

如果多个设备具有相同的能量转换结构，应抽象为同一类设备，通过参数曲线和配置区分。

| 抽象设备类 | 可覆盖设备 | 统一能量结构 | 差异化参数 |
|---|---|---|---|
| 热电联产类 | 燃气轮机 CHP、燃气内燃机 CHP、氢燃料电池 CHP、生物质 CHP | 燃料输入 -> 电输出 + 热输出 | 燃料类型、效率曲线、热电比、排放因子 |
| 电转热/冷类 | 电热泵、电锅炉、电制冷机 | 电输入 -> 热/冷输出 | COP 曲线、温度影响、负载率影响 |
| 热转冷类 | 吸收式制冷机、余热制冷机 | 热输入 + 辅助电输入 -> 冷输出 | COP、辅助电比例、余热品质 |
| 储能类 | 电储能、热储能、冷储能、储氢 | 充能 -> 状态存储 -> 放能 | 能量类型、效率、损耗率、功率容量关系 |
| 可再生发电类 | 光伏、风电 | 资源输入 -> 电输出 | 出力模型、资源曲线、限发策略 |

### 2.3 当前不用但项目通用的接口应预留

设备库接口不能只服务当前某一个场景。即使某些接口当前实验没有使用，只要项目书考核、后续场景或设备复用可能需要，就应在接口层预留。

| 接口类别 | 需要预留的字段 | 目的 |
|---|---|---|
| 经济 | 投资成本、固定运维、可变运维、燃料成本、老化成本 | 支撑经济性考核。 |
| 安全 | 容量上限、出力上下限、SOC、越限量、缺供量 | 支撑可靠性和安全运行考核。 |
| 能效 | 输入功率、输出功率、效率、COP、损耗、弃能 | 支撑能效和能源利用率考核。 |
| 碳排 | 排放因子、运行碳排、生命周期碳排、减排量 | 支撑碳排和低碳考核。 |
| 状态 | 启停状态、运行状态、储能状态、可用状态 | 支撑 EMS 调度和运行分析。 |

### 2.4 区分已实现接口和预留接口

设备库文档和代码实现中应明确区分接口状态。

| 接口状态 | 含义 | 文档标识建议 |
|---|---|---|
| 已实现 | 当前代码已经计算或调用 | `已实现` |
| 待实现 | 项目需要，但当前代码未实现 | `待实现` |
| 预留 | 当前场景不用，但通用设备库建议保留 | `接口预留` |
| 可选 | 仅部分场景或高精度模型需要 | `可选` |

## 3. 统一设备对象结构

每个设备建议抽象为一个标准设备对象，至少包括元信息、端口、容量、经济、安全、能效、碳排、调度输入和运行输出八类字段。

### 3.1 设备元信息接口

| 字段 | 单位 | 类型 | 说明 |
|---|---|---|---|
| `unit_id` | - | string | 设备唯一编号。 |
| `unit_name` | - | string | 设备名称。 |
| `unit_type` | - | string | 设备类型，如 source、load、storage、converter。 |
| `unit_subtype` | - | string | 设备子类型，如 pv、chp、battery、heat_pump。 |
| `scenario_id` | - | string | 所属场景编号。 |
| `enabled` | 0/1 | bool | 是否启用该设备。 |

### 3.2 设备端口接口

| 字段 | 单位 | 类型 | 说明 |
|---|---|---|---|
| `input_ports` | - | list | 输入端口集合，如 electricity、gas、heat、cool、solar_resource。 |
| `output_ports` | - | list | 输出端口集合，如 electricity、heat、cool、emission。 |
| `bus_in` | - | string/list | 输入母线。 |
| `bus_out` | - | string/list | 输出母线。 |
| `energy_carrier_in` | - | string/list | 输入能源类型。 |
| `energy_carrier_out` | - | string/list | 输出能源类型。 |

### 3.3 标准输入接口

| 字段组 | 字段示例 | 单位 | 说明 |
|---|---|---|---|
| `capacity_params` | `rated_power`, `rated_capacity`, `capacity_upper_bound` | kW, kWh | 容量配置和容量边界。 |
| `economic_params` | `capex_annual`, `fuel_price`, `om_cost`, `penalty_cost` | 元/a, 元/kWh | 经济参数。 |
| `safety_constraints` | `power_max`, `power_min`, `soc_min`, `soc_max` | kW, % | 运行安全约束。 |
| `efficiency_params` | `eta`, `cop`, `loss_rate` | p.u., kW/kW, 1/h | 能量转换和损耗参数。 |
| `carbon_params` | `emission_factor`, `lca_factor`, `carbon_price` | kgCO2/kWh, 元/tCO2 | 碳核算参数。 |
| `time_params` | `time_index`, `time_step` | h | 调度时间参数。 |
| `dispatch_signal` | `target_power`, `enable_flag` | kW, 0/1 | EMS 调度指令或启用状态。 |

### 3.4 标准输出接口

| 字段组 | 字段示例 | 单位 | 说明 |
|---|---|---|---|
| `dispatch_outputs` | `input_power`, `output_power`, `state` | kW, kWh | 调度结果。 |
| `energy_outputs` | `energy_input`, `energy_output`, `loss_energy` | kWh | 能量统计。 |
| `cost_outputs` | `investment_cost`, `operation_cost`, `fuel_cost`, `penalty_cost` | 元 | 成本分解。 |
| `safety_outputs` | `violation`, `served_load`, `unserved_load`, `feasibility_flag` | kW, kWh, 0/1 | 安全和可行性结果。 |
| `efficiency_outputs` | `efficiency_actual`, `cop_actual`, `utilization_rate` | p.u., %, kW/kW | 能效结果。 |
| `carbon_outputs` | `direct_emission`, `indirect_emission`, `lifecycle_emission` | kgCO2 | 碳排结果。 |
| `metric_outputs` | `matching_index`, `self_sufficiency`, `curtailment_rate` | kW, %, - | 上层评价指标。 |

## 4. 四类设备统一接口

### 4.1 源侧设备

源侧设备提供外部能源、可再生能源或资源输入，包括电网、天然气、氢气、光伏、风电、地热、外部补热、外部补冷等。

#### 4.1.1 输入接口

| 维度 | 输入参数 |
|---|---|
| 经济 | 能源价格（元/kWh、元/Nm3、元/kg）；投资成本（元/kW）；运维成本（元/kWh 或 元/a）。 |
| 安全 | 接入容量上限（kW）；最大购入功率（kW）；最大反送功率（kW）；资源可用性（p.u. 或 kW）。 |
| 能效 | 资源曲线（W/m2、m/s、°C、kg/h）；出力转换效率（p.u.）；线路或转换损耗（p.u.）。 |
| 碳排 | 能源排放因子（kgCO2/kWh、kgCO2/Nm3、kgCO2/kg）；生命周期排放因子（kgCO2/kW 或 kgCO2/kWh）。 |

#### 4.1.2 输出接口

| 维度 | 输出参数 |
|---|---|
| 经济 | 能源购入成本（元）；运维成本（元）；售能收益（元，接口预留）。 |
| 安全 | 实际购入功率（kW）；实际输出功率（kW）；接口越限量（kW）。 |
| 能效 | 可用功率（kW）；实际利用功率（kW）；弃能功率（kW）；弃能量（kWh）；利用率（%）。 |
| 碳排 | 直接碳排放（kgCO2）；间接碳排放（kgCO2）；替代减排量（kgCO2）。 |

### 4.2 负荷设备

负荷设备表示系统需要满足的电、热、冷、氢、气等需求，可分为刚性负荷和柔性负荷。

#### 4.2.1 输入接口

| 维度 | 输入参数 |
|---|---|
| 经济 | 缺供惩罚成本（元/kWh）；需求响应补偿（元/kWh，接口预留）。 |
| 安全 | 负荷需求曲线（kW）；最大允许缺供比例（%）；可中断比例（%，接口预留）。 |
| 能效 | 负荷类型（电/热/冷/氢/气）；负荷时间分辨率（h）；温度或生产过程关联参数（接口预留）。 |
| 碳排 | 供能来源分摊口径（kgCO2/kWh，接口预留）。 |

#### 4.2.2 输出接口

| 维度 | 输出参数 |
|---|---|
| 经济 | 缺供惩罚成本（元）；需求响应补偿成本（元，接口预留）。 |
| 安全 | 实际满足功率（kW）；未满足功率（kW）；未满足能量（kWh）；负荷满足率（%）。 |
| 能效 | 实际供能量（kWh）；削减量（kWh，接口预留）；转移量（kWh，接口预留）。 |
| 碳排 | 负荷供能分摊排放（kgCO2）。 |

### 4.3 储能设备

储能设备表示电、热、冷、氢、气等能量的跨时段转移单元。

#### 4.3.1 输入接口

| 维度 | 输入参数 |
|---|---|
| 经济 | 功率投资成本（元/kW）；容量投资成本（元/kWh）；固定运维成本（元/a）；循环老化成本（元/kWh-throughput）。 |
| 安全 | 额定充能功率（kW）；额定放能功率（kW）；额定储能容量（kWh）；SOC 上下限（% 或 p.u.）；初始 SOC（% 或 p.u.）；最大充放倍率（1/h）。 |
| 能效 | 充能效率（p.u.）；放能效率（p.u.）；自损耗率（1/h 或 %/h）。 |
| 碳排 | 生命周期排放因子（kgCO2/kWh）；充能来源排放因子（kgCO2/kWh，接口预留）。 |

#### 4.3.2 输出接口

| 维度 | 输出参数 |
|---|---|
| 经济 | 年化投资成本（元/a）；运维成本（元）；老化成本（元）。 |
| 安全 | 当前 SOC（% 或 kWh）；SOC 越限量（% 或 kWh）；充放功率越限量（kW）。 |
| 能效 | 充能功率（kW）；放能功率（kW）；充能量（kWh）；放能量（kWh）；损耗量（kWh）；循环效率（%）。 |
| 碳排 | 储能相关碳排放（kgCO2）；储能转移减排量（kgCO2，接口预留）。 |

### 4.4 转换设备

转换设备表示不同能源形式之间的转换，包括热电联产、电转热、电转冷、热转冷、电转氢等。

#### 4.4.1 输入接口

| 维度 | 输入参数 |
|---|---|
| 经济 | 单位容量投资成本（元/kW）；固定运维成本（元/a）；可变运维成本（元/kWh）；燃料价格或电价（元/kWh、元/Nm3、元/kg）。 |
| 安全 | 额定输入功率（kW）；额定输出功率（kW）；出力上下限（kW 或 p.u.）；爬坡限制（kW/h，接口预留）；启停约束（h，接口预留）。 |
| 能效 | 转换效率（p.u.）；COP（kW/kW）；热电比（p.u.）；辅助电耗比例（p.u.）；效率曲线或负载率曲线（接口预留）。 |
| 碳排 | 燃料排放因子（kgCO2/kWh、kgCO2/Nm3、kgCO2/kg）；用电排放因子（kgCO2/kWh）；生命周期排放因子（kgCO2/kW 或 kgCO2/kWh）。 |

#### 4.4.2 输出接口

| 维度 | 输出参数 |
|---|---|
| 经济 | 年化投资成本（元/a）；燃料成本（元）；用电成本（元）；运维成本（元）；总运行成本（元）。 |
| 安全 | 运行状态（0/1）；实际出力（kW）；出力越限量（kW）；启停次数（次，接口预留）。 |
| 能效 | 输入功率（kW）；输出功率（kW）；输入能量（kWh）；输出能量（kWh）；实际效率（p.u.）；实际 COP（kW/kW）。 |
| 碳排 | 直接碳排放（kgCO2）；间接碳排放（kgCO2）；生命周期碳排放（kgCO2）；减排量（kgCO2，接口预留）。 |

## 5. 相似设备抽象关系

| 统一模型 | 可覆盖设备 | 输入端口 | 输出端口 | 差异化参数 |
|---|---|---|---|---|
| `CHPBase` | 燃气轮机 CHP、燃气内燃机 CHP、氢燃料电池 CHP、生物质 CHP | fuel | electricity、heat | 燃料类型、效率曲线、热电比、排放因子、燃料价格 |
| `ElectricToThermalBase` | 电热泵、电锅炉、电制冷机 | electricity | heat 或 cool | COP、温度影响、负载率曲线、运行电价 |
| `HeatToCoolBase` | 吸收式制冷机、余热制冷机 | heat、electricity | cool | COP、辅助电耗比例、余热品质 |
| `StorageBase` | 电储能、热储能、冷储能、储氢、储气 | energy_in | energy_out | 能源类型、充放效率、损耗率、功率容量关系 |
| `RenewableGeneratorBase` | 光伏、风电 | resource | electricity | 资源曲线、出力模型、限发策略 |

## 6. EMS 调用接口

EMS 不应直接关心具体设备属于哪个场景，而应通过统一设备接口调用设备库。

### 6.1 EMS 输入设备库

| 字段组 | 字段示例 | 用途 |
|---|---|---|
| `capacity_params` | `rated_power`, `rated_capacity` | 限定设备运行边界。 |
| `economic_params` | `fuel_price`, `electricity_price`, `penalty_cost` | 形成调度目标函数。 |
| `safety_constraints` | `power_max`, `soc_min`, `soc_max` | 形成运行约束。 |
| `efficiency_params` | `eta`, `cop`, `loss_rate` | 形成能量平衡。 |
| `carbon_params` | `emission_factor`, `carbon_price` | 形成碳排统计或碳成本目标。 |
| `time_series_inputs` | `load_profile`, `resource_profile`, `price_profile` | 提供时序输入。 |

### 6.2 设备库返回 EMS

| 字段组 | 字段示例 | 用途 |
|---|---|---|
| `dispatch_outputs` | `input_power`, `output_power`, `state` | EMS 记录调度结果。 |
| `cost_outputs` | `operation_cost`, `fuel_cost`, `penalty_cost` | EMS 形成经济指标。 |
| `safety_outputs` | `violation`, `unserved_load`, `feasibility_flag` | EMS 形成安全指标。 |
| `efficiency_outputs` | `efficiency_actual`, `cop_actual`, `loss_energy` | EMS 形成能效指标。 |
| `carbon_outputs` | `direct_emission`, `indirect_emission`, `lifecycle_emission` | EMS 形成碳排指标。 |

## 7. 容量优化调用接口

### 7.1 容量优化传递给 EMS

| 类别 | 参数 |
|---|---|
| 容量变量 | 各设备额定功率（kW）；各储能额定容量（kWh）；外部接口容量上限（kW）。 |
| 经济参数 | 年化投资系数（元/(kW·a) 或 元/(kWh·a)）；设备固定成本（元/a）。 |
| 运行约束 | 设备运行上限（kW）；储能 SOC 范围（%）；外部购能限制（kW）。 |
| 场景数据 | 负荷曲线（kW）；资源曲线（W/m2、m/s、°C）；价格曲线（元/kWh）。 |

### 7.2 EMS 返回给容量优化

| 类别 | 参数 |
|---|---|
| 经济 | 年化总成本（元/a）；运行成本（元/a）；投资成本（元/a）。 |
| 安全 | 负荷满足率（%）；最大缺供功率（kW）；约束违反量（kW、kWh、次）。 |
| 能效 | 综合能源利用率（%）；可再生能源利用率（%）；储能循环效率（%）；源荷匹配指标（kW 或 -）。 |
| 碳排 | 年总碳排放（tCO2/a）；单位供能碳排（kgCO2/kWh）；减排量（tCO2/a）。 |

## 8. 项目书考核指标映射

项目书考核指标应尽量由设备库接口直接计算，避免后处理阶段人工拼接。

| 考核维度 | 考核指标 | 需要的接口字段 |
|---|---|---|
| 经济 | 年化总成本 | `investment_annual_cost`, `operation_cost`, `fuel_cost`, `penalty_cost` |
| 经济 | 运行成本 | `fuel_cost`, `electricity_cost`, `fixed_om_cost`, `variable_om_cost` |
| 安全 | 负荷满足率 | `served_load`, `unserved_load`, `load_satisfaction_rate` |
| 安全 | 运行可行性 | `feasibility_flag`, `constraint_violation` |
| 安全 | 储能安全状态 | `state_of_charge`, `soc_min`, `soc_max`, `soc_violation` |
| 能效 | 可再生能源利用率 | `available_power`, `output_power`, `curtailment_energy` |
| 能效 | 综合能源利用率 | `energy_input`, `energy_output`, `loss_energy` |
| 能效 | 储能循环效率 | `storage_charge_energy`, `storage_discharge_energy`, `storage_loss_energy` |
| 碳排 | 年总碳排放 | `direct_emission`, `indirect_emission`, `lifecycle_emission` |
| 碳排 | 单位供能碳排 | `total_emission`, `energy_output` |
| 碳排 | 减排量 | `avoided_emission`, `baseline_emission_factor` |

## 9. 场景配置方式

场景不应独立重建设备模型，而应通过配置选择设备组合和参数。

| 配置项 | 说明 |
|---|---|
| `scenario_id` | 场景编号。 |

## 10. 当前松山湖代码与统一接口的关系

当前松山湖代码已经具备部分统一接口能力，但还没有完全达到通用设备库规范。

| 接口类别 | 当前状态 | 后续建议 |
|---|---|---|
| 容量接口 | 已具备 PV、GT、HP、EC、AC、ES、HS、CS 容量变量 | 保持，并扩展为统一 `capacity_params`。 |
| 经济接口 | 已具备年化投资、运行成本、电价、气价 | 增加设备级成本分解。 |
| 安全接口 | 具备容量上界和求解可行性 | 增加缺供、越限、SOC、负荷满足率。 |
| 能效接口 | 具备效率、COP、储能损耗和源荷匹配计算 | 增加设备级输入/输出功率和能量统计。 |
| 碳排接口 | 当前主要是预留 | 增加排放因子、碳排输出和碳成本计算。 |
| EMS 输出 | 目前主要输出电网、外部补热/补冷、溢出 | 增加各设备详细出力和状态。 |

## 11. 建议落地顺序

建议按以下顺序推进设备库开发：

1. 先统一设备元信息、端口、容量、经济、能效字段。
2. 再补充安全约束字段，尤其是 SOC、缺供、越限和可行性。
3. 再补充设备级详细输出，包括输入功率、输出功率、状态和损耗。
4. 再补充碳排接口，包括排放因子、碳排输出和碳成本。
5. 最后将不同场景改为设备组合配置，而不是场景独立建模。

## 12. 复用结论

- 设备库应按源、荷、储、转四类抽象建设。
- 场景应是设备组合和参数配置，不应重复开发设备模型。
- EMS 应通过统一接口调用设备库，不应依赖具体场景特例。
- 容量优化应通过统一容量接口传参，并通过统一指标接口读取结果。
- 项目书考核指标应由设备库输出直接计算，尤其是经济、安全、能效和碳排四类指标。
