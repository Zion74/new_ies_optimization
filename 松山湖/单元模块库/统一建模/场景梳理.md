## 系统层级参数情况
### 外部输入参数
| **指标类别**    | **传递的具体参数（涵盖光伏、氢燃料电池、储能等）**     |
| --------------------- | ------------------------------------------------------------ |
| **经济**        | • 设备投资成本及上限（光伏：元/kW；氢燃料电池：元/kW；各种储能：元/kW 及 元/kWh） 应该是投资成本上限，投资成本应该是后面给的• 折现率、设计使用寿命 • 固定及可变运维成本占比 (%) 系统及各设备的固定和可变运维成本• 燃料价格（氢气：元/kg） 应该直接从氢燃料电池输入就可以• 燃料碳排放因子。应该从设备层直接输入 • 售电分时电价 (元/kWh) （大庆系统没有购电）应该在电网接口建模中• 碳税或碳交易价格 (元/吨CO₂) |
| **能效**        | • 光伏：温度系数、额定工作电池温度、逆变器效率曲线 • 氢燃料电池：电效率‑负载率曲线、产热效率曲线、辅机功耗 • 储能：充放电效率、自放电率（超级电容/飞轮）、空转损耗（飞轮）、泵耗（全钒液流） |
| **碳排**        | • 电网碳排放因子 (tCO₂/kWh) • 氢气碳排因子 (kgCO₂/kgH₂) • 各设备全生命周期碳排因子 (kgCO₂/kWh 或 kgCO₂/kg) |
| **安全 / 约束** | • 各储能允许 SOC 范围 (如 0.1~0.9) • 各储能最大充放电倍率 (C‑rate) • 爬坡速率限制 (kW/min) • 燃料电池最小出力比例、启停最小间隔 • 光伏最大允许弃光比例 • 供电可靠性要求 (LPSP) 或备用率下限 |
| **资源 / 负荷** | • 年度8760小时辐照度 (GHI/DNI)、环境温度 • 年度电负荷序列• 氢气供应上限或可获取曲线 |

### 容量优化传递给能量管理系统
| **指标类别**               | **传递的具体参数**                                     |
| -------------------------------- | ------------------------------------------------------------ |
| **容量配置**               | • 光伏额定装机容量 (kW) • 氢燃料电池额定电功率 (kW)、可选热功率 • 各储能设备额定功率 (kW) 和额定容量 (kWh) |
| **设备经济参数**    | • 各设备固定运维成本的小时分摊值 (元/h) • 可变运维成本系数 (元/kWh) • 储能老化成本系数 (元/kWh 吞吐量) • 氢气价格、电网电价作为运行参考（由设备运行出来，参数传递给设备） |
| **设备碳排参数**    | • 各设备运行碳排因子（氢燃料电池按氢气消耗，电网按边际排放因子，储能按吞吐量，储能建设碳排） |
| **设备安全 / 约束** | • SOC 上下限、最大充放电功率 • 燃料电池出力范围、最小启停时间 • 光伏允许的弃光策略或功率因数限值 • 系统备用容量需求 |

### 能量管理传递给容量优化
| **指标类别**    | **传递的具体参数**                                     |
| --------------------- | ------------------------------------------------------------ |
| **经济**        | • 全周期折算总成本：投资年化 + 运维 + 燃料 + 老化更换 • 各时段成本聚合统计 • 失负荷价值或停电惩罚成本 |
| **能效**        | • 光伏实际利用率 (PR) 或容量因数 （设备给）• 燃料电池年均电效率、热电综合效率 （设备给每天或者每次的）• 储能系统往返效率 (全年加权) （设备给每天或者每次的）• 弃光率、系统总损率（设备给每天或者每次的）• 弃光功率 |
| **碳排**        | • 年总碳排放量 (kgCO₂) • 清洁能源供电占比 • 碳排放峰值、超出碳配额频次/总量 |
| **安全 / 状态** | • SOC 越限次数/累计时长 （设备给）• 燃料电池启停次数、低负载运行时长 （设备给）• 设备过流报警次数（或健康状态评估） （设备给）• 供电不足概率 (LPSP) 及最大功率缺口 |

|                    | 可变运维成本         | 元/kWh         |                                  |
|                    | 设计寿命             | 年             |                                  |
|                    | 折现率               | %              | 用于折算年化成本                 |

|                         | 弃光率       | %     | 弃光功率与最大可用功率的比值     |

|                         | 可变运维成本 | 元    | 与实发电量有关                   |
| **输出-碳排放**   | 本时段碳排放 | kgCO₂ | 由实际发电的运维带来的碳排       |
| **输出-能效**     | 瞬时效率     | -     | 实发功率与入射辐照功率之比       |

### 负荷设备
系统直接根据电网调度向电网供电，没有其他的负荷。

| **参数类别**      | **参数**        | **单位** | **说明**                    |
| ------------------------------ | ---------------------------- | --------------------- | ---------------------------------------- |
| **负荷特性**      | 年度/典型日时序电负荷曲线    | kW                    | 必须提供的基础电需求序列                 |
|                                | 允许切负荷比例上限           | %                     | 可中断负荷占比，体现柔性                 |
|                                | 切负荷惩罚成本               | 元/kWh                | 用作供需平衡松弛的惩罚项                 |
| **环境-负荷关联** | 温度-负荷灵敏度系数          | kW/℃                  | 用于修正气温对电负荷的影响（可选）       |
|                                | 外部辐照度-负荷灵敏度系数    | kW/(W/m²)             | 用于修正光照对电负荷的影响（可选）       |
| **经济参数**      | 售电价格（若考虑负荷侧售电） | 元/kWh                | 电负荷反向供电时的价格（通常不涉及）     |
|                                | 失负荷价值 (VOLL)            | 元/kWh                | 未满足负荷的单位经济损失，用于可靠性指标 |
| **控制输入**      | 实际供电功率设定值           | kW                    | EMS优化后分配给该负荷的供电量            |
|                                |                              |                       |                                          |
| **输出-实际消耗** | 实际满足的电负荷             | kW                    | 实际供电功率（≤需求）                    |
|                                | 切负荷功率                   | kW                    | 需求功率与实际供电之差                   |
|                                | 未满足电量                   | kWh                   | 一段时间内累计失电量                     |
| **输出-经济性能** | 切负荷惩罚成本               | 元                    | 切负荷量 × 惩罚成本                      |
|                                | 失负荷经济损失               | 元                    | 按 VOLL 计算的经济代价                   |
| **输出-碳排**     | 间接碳排放                   | kgCO₂                 | 由供电侧的碳排放因子折算（可归于电源侧） |
| **输出-状态**     | 负荷满足率                   | %                     | 实际供电/需求                            |
|                                | 最大功率缺口                 | kW                    | 时间窗内最大单时刻缺口                   |

| **能效**        | 光伏：温度系数、额定工作电池温度、逆变器效率曲线氢燃料电池：电效率-负载率曲线、产热效率曲线、辅机功耗电解槽：产氢效率-负载率曲线、辅机功耗热泵：制热 COP 曲线 / 制冷 EER 曲线（受源温、负载率影响）储能：充放电效率、自放电率（超级电容/飞轮）、空转损耗（飞轮）、泵耗（全钒液流）；冷水罐/热水罐：漏冷/漏热率 (%/h)；氢气罐：漏氢率或蒸发损耗电网接口：变压器/线路损耗系数 |
