# 课题组场景整理任务说明

## 1. 任务背景

我们正在建设“单元模块库 + 场景化系统设计接口”。后续程序需要根据统一格式的场景数据，自动调用设备库、系统模板和优化模型，输出设备容量配置结果。

现在需要先把课题组已有场景按统一模板整理出来。整理工作不要求写代码，重点是把每个场景的用户需求、能源输入/资源、候选设备和数据缺口梳理清楚。

## 2. 整理目标

每个场景最终需要回答 5 个问题：

```text
1. 这个场景是什么？属于哪类应用场景？
2. 用户需要哪些能源？例如电、热、冷、蒸汽、氢、天然气等。
3. 系统可以利用哪些能源输入或资源？例如电网、天然气、光伏、风电、余热、地热、生物质等。
4. 场景里可能配置哪些设备？例如光伏、风机、CHP、电制冷、热泵、电解槽、储氢等。
5. 目前能拿到什么数据？8760 数据、月度总量、典型日曲线，还是只有文字资料。
```

## 3. 交付物要求

每个场景交付一个 Excel 文件，建议复制模板并改名：

```text
课题组场景整理/课题组场景整理模板.xlsx
  -> 场景整理_场景名称.xlsx
```

如果有原始资料，建议按如下结构整理：

```text
课题组场景整理/
└── 场景名称/
    ├── 场景整理_场景名称.xlsx
    ├── 原始资料/
    │   ├── 项目方案.pdf
    │   ├── 负荷数据.xlsx
    │   └── 设备参数表.xlsx
    └── 资料说明.md
```

## 4. Excel Sheet 说明

模板包含以下 Sheet：

| Sheet | 是否优先填写 | 作用 |
|---|---|---|
| `01_场景信息` | 必填 | 说明场景编号、名称、类型、地点、行业、资料来源。 |
| `02_场景能源配置` | 必填 | 声明该场景有哪些用户需求、能源输入和资源条件。 |
| `03_月度用户需求` | 有数据则填 | 整理每月电、热、冷、蒸汽、氢等用户需求总量。 |
| `04_用户负荷需求曲线` | 有数据则填 | 整理每月典型日 24h 曲线或其他逐时需求曲线。 |
| `05_能源输入与资源曲线` | 有数据则填 | 整理太阳辐射、风速、余热、地热、电网、天然气等供给侧数据。 |
| `06_候选设备配置` | 必填 | 整理该场景可能配置的设备和容量边界。 |
| `07_价格与排放参数` | 有数据则填 | 整理电价、气价、氢价、容量费、排放因子等。 |
| `08_资料来源与缺口` | 必填 | 记录每类数据来源、可信度和缺失项。 |
| `09_备注` | 可选 | 记录其他说明。 |
| `10_填写说明` | 参考 | 模板填写规则。 |
| `11_场景类型参考` | 参考 | 15 种场景类型参考。 |
| `12_能源载体字典` | 参考 | 标准能源载体 ID、中文名和单位。 |

如果时间有限，优先填写：

```text
1. 01_场景信息
2. 02_场景能源配置
3. 06_候选设备配置
4. 08_资料来源与缺口
5. 03_月度用户需求
6. 04_用户负荷需求曲线
7. 05_能源输入与资源曲线
8. 07_价格与排放参数
```

## 5. 填写规则

### 5.1 不要混淆“用户需求”和“能源输入/资源”

用户需求是系统最终要满足的能源服务，例如：

```text
电负荷、热负荷、冷负荷、蒸汽需求、氢需求、天然气需求
```

能源输入/资源是系统可以利用或购买的供给侧条件，例如：

```text
电网、天然气、外购氢、太阳辐射、风速、余热、地热、生物质、潮汐
```

示例：

```text
加氢站的“氢需求”是 demand。
外购氢、制氢原料或电解槽输入电力是 input/resource。
```

### 5.2 单位必须写清楚

常见单位建议：

| 类型 | 推荐单位 |
|---|---|
| 电、热、冷功率 | kW |
| 电、热、冷能量 | kWh |
| 氢流量 | kg/h |
| 氢总量 | kg |
| 蒸汽流量 | t/h |
| 蒸汽总量 | t |
| 天然气流量 | Nm3/h 或 kWh |
| 太阳辐射 | W/m2 |
| 风速 | m/s |
| 温度 | C |

如果原始资料单位不同，也请按原单位填写，并在备注中说明。

### 5.3 没有数据要写“缺失”

不要空着不说明。空白无法判断是“不需要”还是“没找到”。缺失信息统一写到 `08_资料来源与缺口`。

示例：

```text
氢需求曲线缺失：只有年总量，没有逐时曲线。
太阳辐射缺失：可后续用气象数据替代。
设备投资成本缺失：可先用默认设备库参数。
```

### 5.4 设备不确定也可以先列为候选

如果不确定某设备是否最终采用，可以先写入 `06_候选设备配置`，`enabled` 填 `待确认`，并在备注里说明。

## 6. 各 Sheet 字段说明

### 6.1 `01_场景信息`

固定列：

```csv
field,value,remark
```

建议字段：

```csv
field,value,remark
scenario_id,,英文或拼音编号，例如 industrial_park_001
scenario_name,,中文场景名称
scenario_type,,参考 11_场景类型参考
location,,地点
industry_type,,行业类型
building_or_project_type,,园区/建筑/交通/油田/钢铁等
currency,CNY,币种
data_source,,项目资料/调研表/PDF/Excel
description,,场景简要说明
```

### 6.2 `02_场景能源配置`

固定列：

```csv
item_id,item_name,item_group,item_type,enabled,default_unit,required,remark
```

`item_group` 可填：

```text
demand   用户负荷需求
input    可购买或可直接利用的能源输入
resource 自然资源、环境条件或可回收资源
```

示例：

```csv
item_id,item_name,item_group,item_type,enabled,default_unit,required,remark
electricity,电,demand,energy_carrier,TRUE,kW,TRUE,用户电负荷
heat,热,demand,energy_carrier,TRUE,kW,TRUE,用户热负荷
cooling,冷,demand,energy_carrier,TRUE,kW,TRUE,用户冷负荷
natural_gas,天然气,input,purchased_energy,TRUE,kWh,TRUE,CHP燃料
solar_resource,太阳辐射,resource,renewable_resource,TRUE,W/m2,FALSE,光伏资源
temperature,环境温度,resource,environment,TRUE,C,FALSE,环境温度
```

### 6.3 `03_月度用户需求`

固定列：

```csv
month,demand_id,energy_amount,unit,days,scaling_policy,remark
```

示例：

```csv
month,demand_id,energy_amount,unit,days,scaling_policy,remark
1,electricity,500000,kWh,31,validate_only,月电量
1,heat,120000,kWh,31,validate_only,月热量
1,cooling,300000,kWh,31,validate_only,月冷量
1,hydrogen,5000,kg,31,validate_only,月氢需求
```

### 6.4 `04_用户负荷需求曲线`

固定列：

```csv
profile_id,month,hour,demand_id,value,unit,remark
```

示例：

```csv
profile_id,month,hour,demand_id,value,unit,remark
M01,1,1,electricity,100,kW,1月典型日电负荷
M01,1,1,heat,20,kW,1月典型日热负荷
M01,1,1,cooling,300,kW,1月典型日冷负荷
M01,1,1,hydrogen,10,kg/h,加氢需求
```

填写规则：

```text
每个月最好 24 行 × 每类需求。
hour 填 1-24。
profile_id 建议写 M01、M02 ... M12。
如果有 8760 数据，可以不填本 sheet，但需在 08_资料来源与缺口说明文件位置。
```

### 6.5 `05_能源输入与资源曲线`

固定列：

```csv
profile_id,month,hour,input_id,input_type,carrier_id,value,unit,price_id,remark
```

`input_type` 可填：

```text
purchased_energy      可购买能源，例如电网、天然气、外购氢
renewable_resource    可再生资源，例如太阳辐射、风速、潮汐
recoverable_energy    可回收能源，例如余热、余压
environment           环境条件，例如温度
```

示例：

```csv
profile_id,month,hour,input_id,input_type,carrier_id,value,unit,price_id,remark
M01,1,1,grid_electricity,purchased_energy,electricity,,kW,electricity,电网可购电，空值表示不限
M01,1,1,natural_gas,purchased_energy,natural_gas,,kWh,gas,天然气
M01,1,1,solar_resource,renewable_resource,solar_resource,0,W/m2,,太阳辐射
M01,1,1,wind_resource,renewable_resource,wind_resource,1.5,m/s,,风速
M01,1,1,waste_heat,recoverable_energy,heat,500,kW,,余热可用功率
M01,1,1,temperature,environment,temperature,12,C,,环境温度
```

### 6.6 `06_候选设备配置`

固定列：

```csv
device_id,device_name,library_id,enabled,optimize_capacity,input_carriers,output_carriers,capacity_ub,power_ub,energy_capacity_ub,unit,remark
```

示例：

```csv
device_id,device_name,library_id,enabled,optimize_capacity,input_carriers,output_carriers,capacity_ub,power_ub,energy_capacity_ub,unit,remark
pv,光伏,pv_standard,TRUE,TRUE,solar_resource,electricity,1000,,,kW,可装屋顶光伏
wind,风机,wind_turbine,FALSE,TRUE,wind_resource,electricity,0,,,kW,无风电则 FALSE
chp,燃气CHP,chp_gas_turbine,TRUE,TRUE,natural_gas,electricity|heat,800,,,kW,
electric_chiller,电制冷,electric_chiller,TRUE,TRUE,electricity,cooling,5000,,,kW,
electrolyzer,电解槽,electrolyzer,FALSE,TRUE,electricity,hydrogen|oxygen,1000,,,kW,加氢站场景可启用
hydrogen_storage,储氢,hydrogen_storage,FALSE,TRUE,hydrogen,hydrogen,,500,2000,kg,
```

### 6.7 `07_价格与排放参数`

固定列：

```csv
param_id,carrier_id,param_type,unit,hour,value,remark
```

示例：

```csv
param_id,carrier_id,param_type,unit,hour,value,remark
electricity_price,electricity,price,CNY_per_kWh,,0.6746,统一电价
gas_price,natural_gas,price,CNY_per_kWh,,0.45,天然气价格
capacity_charge,electricity,capacity_charge,CNY_per_kW_year,,0,容量费
grid_emission,electricity,emission_factor,kgCO2_per_kWh,,0.58,电网排放因子
gas_emission,natural_gas,emission_factor,kgCO2_per_kWh,,0.202,天然气排放因子
```

### 6.8 `08_资料来源与缺口`

固定列：

```csv
data_item,status,source_file,source_page_or_sheet,quality_level,missing_or_issue,remark
```

示例：

```csv
data_item,status,source_file,source_page_or_sheet,quality_level,missing_or_issue,remark
月电量,已获得,项目方案.pdf,表3,较高,,单位为 kWh
冷负荷典型日,已获得,负荷测算.xlsx,Sheet2,中等,,由月度量折算
氢需求曲线,缺失,,,,只有年总量，缺少逐时曲线,需要后续向项目方确认
太阳辐射,缺失,,,,可用气象数据替代,
设备投资成本,缺失,,,,可先用默认设备库参数,
```

## 8. 最终检查清单

提交前请检查：

```text
1. 场景名称和场景类型是否填写。
2. 用户需求和能源输入是否分开。
3. 每个 demand_id 是否在 02_场景能源配置中声明。
4. 每个设备的输入/输出能源是否能看懂。
5. 单位是否填写清楚。
6. 缺失数据是否写进 08_资料来源与缺口。
7. 原始资料是否放入同一场景文件夹。
```
