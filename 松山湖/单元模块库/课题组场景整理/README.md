# 课题组场景整理

本目录用于存放给师弟/合作方填写的场景整理模板、15 场景参考表和烟厂第三场景的数据清洗记录。

| 文件 | 用途 |
|---|---|
| 课题组场景整理任务说明.md | 发给师弟的整理要求，说明每个场景需要提供哪些输入。 |
| 课题组场景整理模板.xlsx | 空白 Excel 模板。 |
| 15种场景+8种能源转换类型-2024092.xlsx | 15 种应用场景和 8 类能源转换参考表。 |
| 课题组场景整理模板_烟厂.xlsx | 师弟整理的烟厂原始 Excel 模板。 |
| 课题组场景整理模板_烟厂_清洗版.xlsx | 程序清洗后的烟厂 Excel 副本。 |
| 烟厂场景接入评估与数据清洗记录.md | 烟厂接入判断、数据质量修复、原始资料核查和通用后端验收记录。 |
