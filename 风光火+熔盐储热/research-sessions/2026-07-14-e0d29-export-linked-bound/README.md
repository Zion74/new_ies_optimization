# E0-D-29 外送耦合上界紧化研究记录

## 决策背景

D28 两个预注册多起点均未提高 336 h 最大端可行下界。下一步转向真正决定区间宽度的 global dual，不再追加随机/启发式符号种子。

## 预注册模型改动

- 保留 D19 成本、弃电与共同年度 PCC 服务；
- 保留 D27 正负差值分解；
- 全部主整数模式与符号二元保持开放；
- 每时段增加 4 条外送/剩余容量有效不等式；
- 增加 1 条年化正负质量平衡和 4 条外送/余量总帽；
- 24 h 为等价性门；336 h 为 1800 s、28 线程上界探针；
- 只有 finite global dual 可以收紧全局上界。

## 结果

机制回归通过。24 h 合并 D27 精确证书后仍为 `26,010.174929 MWh/a` 唯一点，最大正归一化残差 `2.12e-13`。

336 h 在 1800 s 时限返回：

- 可行轨迹 L1：`36,382.462799 MWh/a`，与 D27 下界相同；
- finite global dual：`845,052.030831 MWh/a`；
- 相对 D27 上界改善：`236,597.108500 MWh/a`（`21.8737%`）；
- 相对 gap：`22.22691`，仍未闭合；
- 最大正归一化残差：`6.3615e-13`；
- 全部主整数与符号二元开放，整数可行集未改变。

## 决策

D29 作为有效的全局上界紧化收口，首选 336 h 区间更新为 `[36,382.462799,845,052.030831] MWh/a`。该结果仍只属于替代调度 L1 风险包络，不是实际电价损失、正式 TAC 或技术赢家。下一轮若继续，应审计逐时外送可达上界或优化式 bound tightening，而不是增加随机符号种子。
