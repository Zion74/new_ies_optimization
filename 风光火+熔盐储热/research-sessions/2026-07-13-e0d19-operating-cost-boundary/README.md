# E0-D-19 operating-cost boundary session

本 session 审计 E0-D-18 中未闭合的 PCC 电力结算、碳履约、CHP VOM 与 TES VOM，并构造不依赖猜测固定电价的同 PCC 服务诊断。

结论：同供热、同弃电上限、同年度 PCC 外送已经闭合，固定平价收入差严格为零；24 h TES EAC 燃料上限为 `12.893 million CNY/a`，336 h 为 `15.031–16.330 million CNY/a`。分时电力结算、碳履约和两类 VOM 仍缺项目级证据，不能形成正式 TAC。
