# E0-D-29 外送耦合全局上界紧化产物

本目录保存 D29 的双窗口规范证书：

- `probes/24h.json`：24 h 等价性与严格精确点复核；
- `probes/336h.json`：336 h 1800 s 全局上界探针；
- `e0d29_bound_tightening_certificate.csv`：排除运行时间的确定性双窗口汇总；
- `manifest.json`：上游数据、D27 证书、源码、原始探针和 sidecar 的 SHA-256 锁；
