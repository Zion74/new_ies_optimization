# E0-D-35 TES 无量纲工程材料性敏感性合同

更新时间：2026-07-15

状态：**已按结果前预注册完成。本文档在任何 E0-D-35 求解结果生成前锁定了材料性定义、网格、服务口径、求解精度和主张边界；16 个主算例、4 个自然服务 gap=0 复算、确定性汇总和双端回归现已闭合。该门槛是作者敏感性，不是杨凌项目的真实最小设备规模。**

## 1. 目的

E0-D-34 已证明完整内生容量模型能够求解，但 24 h 自然服务中约 `0.9 t` 的连续 TES 通过补足一个时段约 `0.00022 MWth` 的供热边界改变了 CHP 整数开机组合；1% 严格弃电服务中的 TES/Hybrid 也只有约 `98–104 t`，小于旧参考切片盐量的 1%。E0-D-35 不寻找一个唯一的“现实最小规模”，而是回答：

> 当 TES 的安装盐量和每个实际启用的端口都必须达到同一参考组合的一定比例时，E0-D-34 的微容量结果是否仍存在，严格服务又从何种材料性水平开始需要 TES、BESS 或二者组合？

## 2. 锁定参考组合

无量纲分母只来自已经披露的 E0-D-17 历史机制切片：

- 完整 `LT→HT` 显热容量：`1,200 MWhth`；
- 对应 HITEC 盐量：`13,913.71563843664 t`；
- 公共端口尺度：`150 MW`；
- 温区：`LT/MT/HT = 180/285/390 °C`；
- 盐量换算、温区和端口值继续由 `build_e0d17_tes_spec()` 生成，不在 D35 复制第二套常数。

旧切片的两条抽汽充热端口为零。为避免零分母，D35 明确把 `150 MW` 当作**作者定义的公共端口归一化尺度**，并用于五条可能启用的规划端口；这不是文献给出的抽汽换热器最小模块，也不是杨凌现场设备下限。

## 3. 材料性约束

对每个正材料性比例 (f)，增加 TES 安装二进制 (y_T) 和五个端口安装二进制 (y_p)。盐量满足：

\[
f M_{ref}y_T\le M^{salt}\le \bar M^{salt}y_T.
\]

每个端口 (p\in\{e\!\to\!HT,s\!\to\!HT,s\!\to\!MT,HT\!\to\!MT,e,MT\!\to\!LT,h\}) 满足：

\[
f P_{ref}y_p\le P_p^{cap}\le \bar P_p y_p,
\qquad y_p\le y_T.
\]

并要求：

\[
y_T\le y_{HT\to MT,e}+y_{MT\to LT,h},
\]

即安装 TES 至少启用一条有用输出路径。三座罐体容量均受 (y_T) 的上界联动；既有盐量守恒、2–24 h 时长、充热可达性和两条额定放能认证继续生效。因此：

- TES 可选择 electric-only、heat-only 或 dual-service，不强制两条输出都安装；
- 任一启用端口必须达到材料性下限，未启用端口严格为零；
- 不允许通过“材料性盐量 + 微小端口”继续跨越 CHP 整数边界；
- (f=0) 不增加安装或端口二进制，精确定义为 D34 连续容量基线，而不是一个带零下限的新模型。

## 4. 结果前锁定网格

网格固定为：

| (f) | 解释 | 最小盐量（t） | 每个启用端口最小容量（MW） |
|---:|---|---:|---:|
| 0 | D34 连续容量基线 | 0 | 0 |
| 0.01 | 参考组合的 1% | 139.137156 | 1.5 |
| 0.05 | 参考组合的 5% | 695.685782 | 7.5 |
| 0.10 | 参考组合的 10% | 1,391.371564 | 15.0 |

选择理由在结果前固定如下：1% 覆盖 D34 已暴露的约 100 t 临界区；5% 和 10% 提供两个更高的工程量级带。三点仅用于稳健性与转折识别，不得把其中任一点称为真实工程最低规模。结果生成后不因曲线形状移动或插入主网格点；如需加密，只能另登记为探索性 follow-up。

## 6. 求解与验收

- 求解器仅为 HiGHS；每个并发任务 1 个 solver thread；
- 主精度为相对 MIP gap `0.1%`；若个别算例只能在 `0.5%` 内形成有限上下界，必须单列为 bounded screen，不与 `0.1%` 点值混写；
- 同弃电与同 PCC 残差不得超过 `1e-3 MWh/a`；
- (f=0) 必须与 D34 对应连续基线在求解器上下界/容差内复现；
- (f>0) 时，盐量和五端口的安装二进制、下限、上限及输出路径存在性必须逐项审计；
- 每个结果必须保存 objective primal/dual、实际 gap、总成本、运行成本、容量 EAC、BESS cycle/VOM、燃料、弃电、PCC、盐量、五端口容量、安装二进制和 TES 辅机；
- 所有 JSON 在 OpenBayes 计算后记录 SHA-256，再生成确定性汇总。

## 7. 允许的解释

允许：

- “连续微容量结果在某材料性带下消失/保留”；
- “严格服务在公开代理参数下需要某种非零储能组合”；
- “材料性假设使容量、整数开机组合或目标区间发生变化”；
- “Hybrid 折叠为 TES/BESS/No-storage”，前提是按既有移除技术与材料性规则复核。

禁止：

- 把 1%/5%/10% 写成杨凌实际最小规模；
- 把公开成本组合写成杨凌正式 TAC；
- 只比较 incumbent 而忽略重叠的 objective bounds；
- 把热 MW 与电 MW 相加形成一个“总功率占比”；
- 依据 D35 结果修改本合同的主网格或服务值；
- 宣称 E2 正式经济前沿或项目技术赢家已经启动。

## 9. 冻结结果

所有主算例均通过同弃电/PCC 服务和材料性逐项审计。自然服务中 5%/10% 的首轮 `0.1%` gap 解已选择零 TES，但 incumbent 略差于已知无储能证人；结果解释前按预注册的数值验收原则对这四个身份执行 gap=0 复算，均精确回到 `544.847466606 million CNY/a`。规范汇总只采用复算值。
