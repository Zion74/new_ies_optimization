# E0-D-27 方向生成与符号重构数值证书合同

更新时间：2026-07-14

状态：**24 h 最大化已精确闭合；336 h 固定方向生成了严格可行证人，正负差值分解将全局上界比 D26 收紧 20.59%，但 1800 s 内仍未闭合。D27 只修正替代调度 L1 包络的数值证书，不指定实际价格，不构成正式 TAC，也不开放 E1。**

## 1. D26 之后仍需处理的问题

D26 已解决年度成本/弃电 cap 的尺度问题，并强制严格残差与已知证人支配，但最大化仍沿用 D23 的 `2M` 绝对值上界。24 h 独立方向支持求解找到严格可行值 `26,010.174929016 MWh/a`，高于 D26 big-M 模型自报的全局上界 `26,010.174917651 MWh/a`，相差约 `1.14e-5 MWh/a`。差值很小，却足以否定“到 6 位小数精确闭合”的证书表述。

D27 不改变 D19/D23 的可接受调度集合，而是分别解决：

1. 如何不依赖符号 big-M 生成更强的可行 L1 证人；
2. 如何用更紧的等价符号模型重新取得可核验的全局 primal/dual。

## 2. 固定支持方向

对符号向量 \(s_t\in\{-1,+1\}\)，定义

\[
J_s=\frac12\sum_t w_t\Delta t\,s_t
\left(P_t^{TES}-P_t^{NS}\right).
\]

任意可行调度均满足 \(J_s\le J_{L1}\)。固定 \(s\) 后，目标是线性的，不再需要 336 个绝对值符号二元；两架构的 CHP/TES 主整数模式仍全部开放。求解后按新轨迹符号更新 \(s\)，直至符号稳定或达到预注册迭代数。

支持方向结果的使用边界：

- 返回轨迹重算的 \(J_{L1}\) 是全局原问题的合法可行下界证人；
- 支持子问题的 dual 只界定该固定方向，**不是**全局 L1 上界；
- 符号固定点只表示方向迭代稳定，不等于遍历所有 \(2^T\) 个符号模式。

## 3. 正负差值分解

全局最大化改写为

\[
\Delta_t=p_t^+-p_t^-,\qquad
|\Delta_t|=p_t^++p_t^-,
\]

\[
0\le p_t^+\le Mz_t,\qquad
0\le p_t^-\le M(1-z_t).
\]

该模型保留每时段一个符号二元，但将原来的两条 `2M` 上界替换为两个 `M` 限制和等式分解。它与原绝对值模型代数等价，主整数与符号模式全部开放。只有该模型返回有限 dual、严格残差通过且 incumbent 不劣于方向支持证人时，dual 才可作为全局 L1 外界。

## 5. 336 h 验收

| 项目 | 结果 |
|---|---:|
| D26 全局最大严格区间 | `[36,382.462799, 1,362,149.106858] MWh/a` |
| 固定方向 primal / dual | `36,382.462799 / 42,290.912450 MWh/a` |
| 固定方向 relative gap | `0.162398287` |
| 方向轨迹重算 L1 | `36,382.462799 MWh/a` |
| 正负分解全局 primal / dual | `36,382.462799 / 1,081,649.139331 MWh/a` |
| 正负分解 relative gap | `28.729959330` |
| 最大正归一化残差 | `2.0145e-12` |
| 支持/L1 与全局 L1 重算误差 | `0 / 0 MWh/a` |
| 两条任务终止 | `maxtimelimit`（1800 s） |

固定方向在首轮即达到符号固定点，没有改善 D26 的可行下界；其 dual `42,290.912450 MWh/a` 只是该方向的上界。等价正负分解的有限 dual 则是合法全局上界，将 D26 上界收紧 `280,499.967527 MWh/a`（`20.5925%`）。因而 D27 的首选 336 h 最大严格区间为

\[
[36{,}382.462799,\ 1{,}081{,}649.139331]\ \mathrm{MWh/a}.
\]

该区间仍很宽，只能报告“全局外界进一步收紧”，不能报告 336 h 最大值已求出。

无论 336 h 是否缩小外界，都必须分别报告：方向支持可行 L1、正负分解全局 primal、有限 dual、relative gap、严格残差和终止条件。不得把支持方向 dual 或局部整数邻域 dual 写成全局外界。

## 6. 允许与禁止的表述

允许：

- “固定支持方向移除符号二元，并生成严格可行的 L1 证人”；
- “正负分解与原问题代数等价，有限 dual 可作为全局外界”；
- “D27 修正了 D26 最大端的最后一处微小符号数值偏差”。

禁止：

- 把固定方向 dual 当成全局 L1 上界；
- 把符号固定点称为全局最优证明；
- 把未覆盖全部主整数空间的邻域 dual 当成全局 dual；
- 把 D27 改写为实际电价、结算收益、正式 TAC 或技术赢家；
- 因数值证书改善而启动 E1–E6。
