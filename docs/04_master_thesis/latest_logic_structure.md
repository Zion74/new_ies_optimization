# 硕士论文：最新逻辑结构

更新时间：2026-07-14

## 1. 总体定位

硕士论文以杨凌热约束型风—光—火系统为唯一主对象，统一回答三个递进问题：

1. 哪种新能源规划状态会在何时产生多强的灵活性服务需求？
2. 这些灵活性应由锂离子 BESS、双用途熔盐 TES 还是 Hybrid 提供？
3. 如何把确定性模型转化为可验证、可审计的场景化决策支持？

一句话主线：

> 从源荷匹配识别灵活性需求，经公平容量—运行优化得到储能技术选择边界，再由受约束的 Agentic 工作流完成场景输入、模型调用、物理审计和可追溯解释。

负荷预测不再承担硕士论文主线。

## 2. 推荐章节结构

### 第 1 章：绪论

- 热约束 CHP、新能源接入和储能技术选择背景；
- 高等级文献下的研究进展与空白；
- 三个研究问题、技术路线和贡献边界；
- 论文组织结构。

### 第 2 章：杨凌系统、数据与统一模型

主问题：**研究对象、数据和物理经济口径是否可信？**

- 2×350 MW CHP、签约陕北风电、本地 PV 与公共并网点；
- 2024 年 8784 h 电功率、供热、新能源和价格数据；
- 两台机组的启停、爬坡、热电可行域和煤耗；
- BESS 的功率、能量、SOC、退化和更换；
- 双品位熔盐 TES 的端口、盐量、效率和能质方向；
- 年化经济模型、碳口径和 HiGHS 求解验证。

本章只验证模型，不宣布储能技术优劣。

### 第 3 章：基于源荷匹配的新能源接入规划与灵活性服务需求识别

主问题：**哪种规划状态会在何时产生多强的灵活性服务需求？**

- 将 IEMI / EQD 或其简化指标迁移到杨凌风—光—热致强迫发电场景；
- 识别源荷冲突强度、关键时段和外送通道暴露；
- 规划风光接入，并把灵活性需求表述为 ε 目标、冲突功率、冲突持续能量与关键时段，而不是预先给出 BESS/TES 的 MW/MWh；
- 输出第 4 章统一使用的 \(H^* / G^* / R_W / I_{HC}\)、ε 和低/中/高冲突状态；
- 德国 / 松山湖只作方法迁移或附录证据，不作为章节案例主线。

本章不预先指定灵活性必须由哪种储能提供，也不输出具体储能设备容量。

### 第 4 章：BESS—熔盐 TES 的价值机制与适用边界

主问题：**在什么条件下选 BESS、TES、Hybrid 或不配储能？**

- 无储能 / BESS / TES / Hybrid 四架构；
- 同供热安全、同弃风上限下的最小年化成本；
- BESS 退化与更换、TES 分端口/分品位成本；
- 电量时移、热替代、强迫出力释放价值分解；
- 热约束 × 通道紧张度主地图，按风电分面；
- 时长 × 相对成本第二地图；
- 代表周扫描与杨凌 8784 h 回代。

本章即当前主 SCI，详细计划见 `chapter4_tes_ees_regime_boundary_plan.md`。

### 第 5 章：可验证的 Agentic 规划决策支持

主问题：**如何让前两章模型被可靠、可追溯地使用？**

Agentic 只负责：

```text
自然语言需求
→ Scenario Schema
→ 单位/范围/完整性校验
→ 调用第 3、4 章确定性优化器
→ 独立物理与证据审计
→ 生成带来源的解释
→ 人工确认
```

对比人工脚本、普通 LLM 和 Agentic 工具链，评价参数抽取准确率、非法约束识别率、调用成功率、可复现性、物理违规漏检率、无证据建议率和人工耗时。

Agent 不直接替代 MILP，不修改物理规律，不自主发布规划结论。详细计划见 `chapter5_agentic_decision_support_plan.md`。

### 第 6 章：结论与展望

- 总结灵活性识别、储能选择边界和可信决策支持三条结论；
- 明确适用系统和未覆盖服务；
- 将负荷预测、随机优化和滚动运行列为独立成果或后续方向，而不是补写成当前结论。

## 3. 章节递进与防重复

| 章节 | 只回答 | 不回答 |
|---|---|---|
| 第 2 章 | 模型是否可信 | 哪个储能更优 |
| 第 3 章 | 新能源规划状态、灵活性服务强度与 ε | BESS/TES 谁赢或设备容量 |
| 第 4 章 | 哪种技术在何种条件下最优 | 如何用 LLM 自动决策 |
| 第 5 章 | 如何安全调用与审计模型 | 重新求解或改写物理模型 |

## 4. 已有成果的安置

- 源荷匹配会议稿：第 3 章方法来源；
- 负荷预测会议稿：独立成果，不占硕士论文章节；
- 德国 / 松山湖 EQD 结果：辅助迁移证据或附录；
- 旧 Carnot battery / EQD SCI：独立历史稿，不再定义第 4 章；
- 杨凌同规格储能会议结果：第 4 章机理预实验，不能作为公平经济结论；
- 当前主 SCI：第 4 章凝练稿；
- Agentic：只有通过对照评价后才构成第 5 章内容。

## 5. 当前状态与先后顺序

1. 先完成第 2 章所需的数据审计和统一 MILP；
2. 用小样本完成第 4 章 E0/E1，确认公平口径和物理约束；

4. 第 3 章只做与第 4 章输入真正相关的杨凌源荷匹配，不重跑无关案例；
5. 等第 3、4 章模型 API 稳定后再做 Agentic，避免把尚未稳定的脚本包装成系统。
