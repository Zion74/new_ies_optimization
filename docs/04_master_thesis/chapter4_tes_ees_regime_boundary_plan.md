# 硕士论文第 4 章：BESS—熔盐 TES 适用边界计划

更新时间：2026-07-16

## 1. 本章使命

本章承接第 3 章得到的灵活性需求和低/中/高冲突状态，回答：

> 同样满足供热安全和新能源消纳要求时，何时应配置 BESS、双用途熔盐 TES、Hybrid，何时不值得配置储能？

本章是当前主 SCI 在硕士论文中的完整版本。SCI 强调可迁移边界，本章还需补足数据口径、模型验证、杨凌工程解释和与第 3 章的衔接。

## 2. 章节结构

### 4.1 问题定义与公平口径

- 四架构；
- 同服务最小年化成本；
- 同预算最低弃风率对偶验证；
- 5% 经济无差异带和不可行区域；
- 同 MW/MWh 只作机制控制。

### 4.2 技术特定容量—运行模型

- 双机 CHP 与热致强迫出力；
- BESS P/E、SOC、退化和更换；
- HT/MT 熔盐、分端口投资、盐量和品位方向；
- 单一 PCC 与净辅助用电；
- Pyomo + HiGHS 综合 MILP。

### 4.3 价值机理分解

- 电量时移；
- 电转热；
- 热量跨时转移；
- CHP 强迫电出力释放；
- Hybrid 非加性协同。

### 4.4 公平经济前沿

- 杨凌基准点 ε 前沿；
- 容量、时长、燃煤、碳排和启停；
- 同预算对偶结果；
- 解释当前 `17% → 10.8% → 5%` 为什么只能是前导机制证据。

### 4.5 物理适用域

- 热约束 \(H^*\) × 架构无关的 PCC 容量比 \(G^*=C^{PCC}/P_{CHP}^{rated}\)；
- 三档风电容量分面；
- No storage / BESS / TES / Hybrid / Indifferent / Infeasible；
- 用架构无关的 \(I_{HC}\) 与 \(\Gamma_C^0\) 解释边界。

### 4.6 经济适用域

- 时长 \(D\) × 相对年化成本 \(\kappa\)；
- 不同物理冲突状态分面；
- 端口成本和能量成本的分解敏感性。

### 4.7 8784 h 验证与工程含义

- 代表周容量固定回代；
- 关键边界点全年重优化；
- 误差、后悔值和边界移动；
- 杨凌真实点与可能的风电增长 / PCC 降容路径。

### 4.8 限制

- 不覆盖调频、黑启动等快速服务；
- 不覆盖预测误差、随机优化和滚动控制；
- 结论适用于承担供热义务、存在新能源富余和接口约束的 CHP 联营系统。

## 3. 与第 3 章的接口

第 3 章只向本章提供：

- 风光接入规模及 \(R_W\)；
- 架构无关的 \(H^*\)、\(G^*\)、\(I_{HC}\) 和 \(\Gamma_C^0\)；
- 弃风服务目标 ε、冲突功率与连续冲突能量；
- 低/中/高物理状态及关键冲突周。

本章在这些服务输入下独立优化 BESS 与 TES 的功率、盐量/能量和端口容量。第 3 章不得输出 BESS/TES 设备 MW/MWh 或提前固定“熔盐一定更好”，本章也不重复论证源荷指标本身的优越性。

## 4. 验收门槛

本章形成可写结果前必须满足：

1. E0 物理和数据测试全部通过；
2. 所有架构用同一输入、PCC、热安全和 ε；
3. BESS 计退化与更换，TES 计全部端口和寿命；
4. 代表周与全年 TAC 误差不超过 3%，弃风不超过 1 个百分点；
5. 边界点报告 MIP gap、次优差和 5% 无差异带；
6. 至少一个 BESS 区、一个 TES 区和一个边界点通过 8784 h 重优化；
7. 如果 Hybrid 未形成稳定区域，诚实报告而不是调整阈值制造结论。

当前已完成 E0-D-1–D-37 的数据、物理、经济边界、材料性、代表周和分块循环状态门，D38/R1/D39 的时间聚合失败、D40–D43 的全年求解/证书失败均已保留。D44/D47 已闭合三架构严格下界，D46 三架构均无 incumbent。D48-R1 唯一正确路径总批次已完成：BESS/TES/Hybrid 均未产生 candidate、repair、容量或上界，只能登记 `no_primal_status_closure`；总 manifest `ca024880...`。D49 物理优先燃料投影合同已结果前冻结，下一步只做 Gate A 和通过后的单次 BESS 方法门；当前尚无 D49 数值。因此正式 TAC、gap、E2–E4 边界扫描和技术排序仍不得启动。
